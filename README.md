# dónde

A travel tracker that fills in a world map as you record where you've been.

Two maps: one shades whole countries, one shades only the cities you actually stood
in. Zoom in and every city nearby appears as a hollow ring you can tap to tick off —
the map is where you record things, not just where you look at them.

Everything runs offline. 34,124 cities, 252 countries, every US National Park unit and
the wonders lists are compiled into an 8.7 MB database that ships inside the app. No
account, no server, no subscription. Nothing you record leaves your phone.

Built because the existing apps either look bad or charge for the city map.

## What it does

- **Two maps** — countries and cities, with country labels and eight colour themes
- **Tap to record** — zoom in, tap a city ring, it fills
- **Dates** at whatever precision you remember: `2019`, `April 2019`, or a full day
- **Named checklists** — "Japan 2027", "Parks to finish". Marking somewhere visited
  ticks it on every list at once
- **Stats** — share of the world, its land, and its population; by continent, by year,
  and a histogram of which months you travel
- **Rarity** — every city carries a percentile, so 40 cities across the Sahel scores
  differently from 40 European capitals
- **18 badges**, including ones a country counter can't see — Polar Circle, Road Less
  Travelled, The Full 63

## Rarity, briefly

The honest measure of how rare a place is would be "what fraction of travellers have
been here", which needs data nobody has. So it's estimated: city population blended
with how touristed its country is (World Bank arrivals), then **ranked into
percentiles across the whole catalogue**.

That last step matters. In absolute terms the scores pile up between 35 and 50 and
nothing reaches 80, so every city reads "about 42". Ranked, *rarity 90* means rarer
than 90% of the 34,124 cities in the database.

| | |
|---|---|
| Paris | 1 |
| Bangkok | 1 |
| Bamako | 38 |
| Ouagadougou | 72 |
| Reykjavík | 84 |
| N'Djamena | 96 |

It's a prior, not a verdict — absolute arrivals over-reward small countries, which is
why Iceland scores higher than it deserves.

## Running it

**Requires Xcode 26 or newer.** Expo SDK 57 depends on a package requiring Swift 6.2;
older Xcode fails with a blank `Could not resolve package dependencies:` and no reason
attached. If you're on Xcode 16.x, build through EAS instead.

```bash
# 1. Build the catalogue. The NPS key is optional and free —
#    without it everything works except US parks.
cd tools
npm install
NPS_API_KEY=your_key npm run build

# 2. Run the app. MapLibre is a native module, so Expo Go won't load it.
cd ..
npm install
npx expo run:ios
```

A free NPS key takes a minute from
[nps.gov/subjects/developer](https://www.nps.gov/subjects/developer/get-started.htm).

Typecheck with `npx tsc --noEmit` in the root and again in `tools/`.

## How it's built

**Expo · React Native · MapLibre · SQLite + Drizzle · Zustand**

Two databases that are never joined in SQL. `reference.db` is the read-only catalogue,
regenerated by the pipeline and replaceable wholesale. `user.db` holds your visits and
has to survive forever. Cross-referencing happens in JS against an in-memory visit set.

`tools/` is a separate package that turns public datasets into the bundled catalogue.
It's deterministic — the same inputs produce a byte-identical database, so rebuilding
with unchanged sources produces no diff.

```
src/db/        schema.ts (Drizzle) · reference.ts (read-only catalogue)
src/stores/    visits.ts · lists.ts · settings.ts
src/lib/       stats.ts, badges.ts, rarity.ts, dates.ts — all pure functions
src/map/       WorldMap.tsx · style.ts
src/app/       expo-router screens
tools/         the offline data pipeline
assets/data/   GENERATED — reference.db + countries.geojson
```

[`docs/PLAN.md`](docs/PLAN.md) has the architecture reasoning and the roadmap.

## Data

Built from [GeoNames](https://geonames.org) and
[World Bank Open Data](https://data.worldbank.org) (both CC BY 4.0),
[Natural Earth](https://naturalearthdata.com) (public domain), and the
[NPS API](https://www.nps.gov/subjects/developer/) (US public domain). Map tiles from
[OpenFreeMap](https://openfreemap.org), © OpenStreetMap contributors.

Full terms in [`docs/ATTRIBUTION.md`](docs/ATTRIBUTION.md). If you add a source, add it
there first — a dataset reaching users without a licence entry is the one bug you
can't fix by shipping an update.

## Status

A personal project, built for one traveller and shared in case it's useful. No
